# and MathsAnswerTests checks them: 3,348 answers, the test's MATHS_ANSWERS.

# which are decimal:
#
#   DivideByte AX DIVISOR = AL AH                    a byte divide, through the game's trap when it overflows
#   DivideWord DXAX DIVISOR = AX DX                  a word divide, likewise
#   DivideSignedWord DXAX DIVISOR = AX DX            a signed word divide, likewise
#   DivideUnsigned DXAX DIVISOR at RETURN = AX DX    the divides whose trap reads the instruction before CS:RETURN
#   NextRandom A B C = NUMBER                        randomState0-2 before the step, and the number it makes
#   SinCosOf ANGLE = SINE COSINE                     every angle of 2,048 to a turn, then 0800 and ffff
#   RotateBySinCos FIRST SECOND by SINE COSINE = FIRST SECOND
#   ArcTangent2 A B = ANGLE
#   RatioArcTangent NUMERATOR DENOMINATOR = ANGLE
#   QuadrantArcTangent A B = ANGLE
#   VectorLength X Y Z = LENGTH
#   VectorWithinBox X Y Z HALFSIZE = 1 or 0
#   AngleWithinTolerance A B TOLERANCE = 1 or 0
#   ShiftRight24 VALUE COUNT = VALUE
#

# header.
